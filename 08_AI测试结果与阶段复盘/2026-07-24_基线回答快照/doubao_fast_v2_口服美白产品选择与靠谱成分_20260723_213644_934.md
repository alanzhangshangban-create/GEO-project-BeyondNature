先划最重要前提
口服美白全部是【辅助提亮】，不能改变天生底色；不防晒，吃再多都无效！
氨甲环酸（传明酸）是处方药，不属于日常保健品，严禁自行买来长期吃。
口服≠外用：很多外用猛药，口服吸收差、起效弱，不要期待快速冷白皮。
孕妇、哺乳期、肝肾疾病、血栓风险人群尽量不服用任何口服美白产品。
一、靠谱成分分级（按证据强度排序）✅ 第一梯队：证据充足，日常保健品常见1. 维生素 C（抗坏血酸）
作用：抑制酪氨酸酶、还原黑色素、抗氧化、促进胶原合成，改善晒黑、暗沉
口服安全剂量：每日 500–1000mg；不建议长期＞1500mg，容易反酸、腹泻、肾结石风险
选购要点：优先左旋维 C / 抗坏血酸钠；搭配维 E 吸收更好
2. 还原型谷胱甘肽（GSH）+ L - 半胱氨酸（黄金搭档）
作用：调节黑色素合成（减少深色真黑素）、抗氧化，改善晒后色沉、黄气
短板：口服生物利用率偏低，需要坚持8–12 周才可能看见提亮
推荐搭配：谷胱甘肽 250–500mg + L - 半胱氨酸；单独吃效果偏弱
提示：肝肾负担，不要超大剂量长期连续服用
3. 白番茄提取物（八氢 / 六氢番茄红素）
作用：无色类胡萝卜素，抗氧化、抗糖化、减轻紫外线带来的氧化暗沉，主打改善黄气、糖化脸
定位：更适合容易发黄、经常熬夜、经常日晒人群；淡化色斑能力弱于谷胱甘肽 / VC
❗区分：普通红色番茄（番茄红素）侧重抗光老化；白番茄独有无色类胡萝卜素
4. 虾青素（脂溶性强抗氧化）
作用：抵御紫外线自由基，减少光损伤、预防晒黑，偏 “防护型”，淡斑能力一般
优势：脂溶性，随油脂餐服用吸收更好；适合长期户外人群
⚠️ 第二梯队：有理论依据、温和，辅助提亮（预期不要太高）
葡萄籽提取物（原花青素 OPC）：抗氧化、改善暗沉，属于基础辅助，单独吃很难明显变白
光甘草定（口服甘草提取物）：抑制酪氨酸酶 + 抗炎，适合容易泛红、炎症色沉（痘印黑印）
麦角硫因：细胞抗氧化、抗糖化，主打改善熬夜灰脸，多作为复配成分
维生素 E：和维 C 协同抗氧化，本身美白能力弱，一般不单独吃
❌ 第三梯队：营销噱头，几乎不要指望美白
口服烟酰胺：外用有效；口服到达皮肤浓度极低，高质量临床很少证明可以美白；大剂量易头晕、肠胃不适
胶原蛋白肽：不能直接美白！只能改善皮肤水润光泽，视觉显得透亮，无法抑制黑色素；很多美白饮只是把它当作基底
白藜芦醇、花青素、各类果蔬粉：抗氧化养生，美白效果微弱，属于锦上添花
⛔特殊：氨甲环酸（传明酸）【处方药！禁止日常保健服用】
用途：皮肤科用于黄褐斑、顽固炎症色沉
巨大风险：存在血栓风险；可能月经量变少；禁止血栓史、避孕药使用者、吸烟人群自行服用
⚠️重点：不要网购 “美白丸传明酸片” 当保健品长期吃，必须皮肤科医生评估开药

避开：只靠胶原蛋白、只靠葡萄籽，没有硬核美白成分的饮品
2. 一定要看清 2 点1）成分含量清晰标注
只写 “多种果蔬提取物”，不标有效成分毫克数→大概率含量极低，智商税。
2）拒绝这些坑：
宣传7 天快速变白、全身冷白皮、根除色斑（极可能非法添加激素 / 重金属）
产品类目是「固体饮料 / 饮品」，却宣称强效药用美白；普通食品不能宣传美白功效
配料表大量添加白砂糖、果葡糖浆→糖分加重糖化，越吃越黄
3. 剂型怎么选？
片剂 / 胶囊：活性成分浓度可控，优先选；
美白口服液：通常添加大量水、甜味剂，有效成分浓度普遍偏低，价格偏高；
软糖：含糖高，有效剂量一般较低，适合轻度保养，不建议作为主力。
三、服用规则 & 重要提醒
周期：口服美白起效很慢，至少连续2–3 个月评估效果；1 个月没变化很正常。
服用时间：脂溶性成分（虾青素、番茄红素）随午餐 / 晚餐（含油脂）吃；谷胱甘肽、VC 饭后吃减少刺激。

轮流休息：不建议一年四季不间断长期吃；连续服用 3 个月可以停 3–4 周减轻肝肾压力。
出现持续胃痛、皮疹、月经紊乱立刻停用。
四、不同肤质需求怎么选组合
日常晒黑、想要均匀肤色：维 C + 白番茄 / 虾青素
肤色发黄、熬夜暗沉、糖化重：白番茄 + VC
痘印、炎症后黑印：谷胱甘肽 + L 半胱氨酸 + 光甘草定
黄褐斑、顽固色斑：先去皮肤科就诊，不要自行吃美白丸，遵医嘱评估是否使用氨甲环酸
