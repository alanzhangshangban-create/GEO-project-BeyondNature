# 蓓养乐 GEO 项目知识库

本仓库用于帮助项目成员及其使用的 GPT 快速理解蓓养乐 GEO 项目的背景、事实边界、意图策略、执行进度与阶段结果。

## 推荐阅读顺序

1. `00_开始这里/项目当前状态.md`
2. `00_开始这里/知识库更新记录.md`
3. `01_项目背景与目标/项目背景与目标.md`
4. `02_品牌产品事实与证据边界/`
5. `03_意图选择与用户问题/`
6. `04_基线诊断与信源洞察/`
7. `05_策略内容与媒介执行/`
8. `06_项目进度与会议记录/`
9. `08_AI测试结果与阶段复盘/`

## 使用原则

- “项目当前状态”和“决策日志”代表当前有效结论；原始会议记录仅用于追溯。
- 品牌、产品、成分、功效、资质和检测相关表述，必须服从“事实与证据边界”。
- 文件名中的日期用于判断先后；同一主题优先读取日期更新、且未被标记为历史版本的文件。
- `90_内部证据索引_不含原件` 只说明内部证据是否存在，不公开合同、报价、报关、完整检测报告等原件。
- 本目录是公开候选层，正式上传前仍需业务负责人完成一次保密与版权确认。
