# 项目进度表更新说明

项目进度表是 GPT 判断“目前做到哪一步”的主要依据，建议保留以下字段：

| 字段 | 说明 |
|---|---|
| 工作模块 | 事实梳理、意图、内容、媒介、发布、测试、复盘等 |
| 具体任务 | 可交付、可验收的任务名称 |
| 当前状态 | 未开始、进行中、待确认、已完成、暂停 |
| 负责人 | 内部、品牌或供应商责任人 |
| 计划完成时间 | 当前计划日期 |
| 实际完成时间 | 完成后填写 |
| 交付物链接 | 指向本知识库中的具体文件 |
| 验收标准 | 如何判断完成 |
| 风险/阻塞 | 当前问题和依赖 |
| 最后更新时间 | 用于判断信息新旧 |

建议文件名：`YYYY-MM-DD_蓓养乐GEO项目进度表.xlsx`。上传新版本后，将旧版本移入历史归档，并同步更新 `00_开始这里/项目当前状态.md`。
